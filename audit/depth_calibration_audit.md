# 阶段 0.5：RGB-D 测量验收

**结论：暂缓正式 RGB-D 组。** 2024 数据的深度编码可按毫米解释，早期 Reference 盆具量测也支持这个量级；现场测距精度仍未验证，未找到可跨日期及调距复用的盆顶参考面。18 个目标仍满足阶段 0 的目录条件，**0/18 有经本轮验收的 H90 历史帧**。未拟合果重、作物模型或观测算子。验收从干净的 `faf2852` 开始，称重、目标、截点、留一隔间分折和环境输入协议保持原样。

## 历史覆盖与筛选

按基线的 Amsterdam `2024-09-03 00:00` 起点和 `2024-09-23 / 10-08 / 10-22 17:00` 闭区间截点映射 UTC。每室有 84 / 144 / 200 对索引帧，窗口去重后各室 200 对，总计 1,200。期内都是 UTC+02:00，不跨 10 月 27 日换表。实际 Range 范围以六室各自最后一个截点为止，压缩成员总计 18,690,811,212 字节（不含每次读取的局部 ZIP 头等开销）。每次运行只审核窗口并集，同帧不按目标重复解码；复跑优先复用通过 CRC 的本地成员。既不使用截点后的视觉信息，也不重新选择分折或改动环境协议。

严格区分以下口径：`directory_pairs` 为文件名精确配对；`decoded_pairs` 为两份实际解码且配置网格一致；`available_rgb_frames` 为独立 RGB 解码、色差掩码非空且非几乎全黑；`common_rgbd_frames` 是其中两份均解码且掩码内至少一半编码有效深度的**共同基础筛查帧**；`qualified_h90_frames` 还要求现场尺度和盆顶参考面验收。RGB 用全图、固定阶段 0 `G−R≥6`、`G−B≥−12`、`G≥25`，无新训练阈值。黑屏用每 8 像素的网格抽样，RGB 最大通道小于 16 的像素达到 95% 记作近黑。掩码非空不代表语义准确，深度有效不代表测距准确。这两类“可用”只是透明的基础筛查下界，不代表已达到机理对照要求。届时两组须消费**同一合格帧及掩码**，不能采用各自最大帧集。

## 决策和后续所需证据

- **已验证**：档案映射、毫米编码依据、实际逐成员双模态读取和诊断范围、Reference 标称盆径的独立量级核验、盆顶候选区无法支持纵向验收。
- **当前仅可探索性分析**：在共同基础筛查帧记录掩码内编码有效比例、`masked_z_median_raw`（乘 0.001 后只是相机轴向距离）及局部点云形状；先按同相机和构图分层，不解释为高度、叶面积或生物量，不作为果重或机理对照输入。低分光照、植物颜色、调距与无遮挡背景可共同作用于掩码，深度缺失也可能依赖视场和光照。
- **仍待验证**：至少需要每台相机可追溯的现场尺度目标与误差容限、全视野配准残差、同日期可复核的多个非冠层盆顶控制点，或独立标定的台面到盆顶偏移与相机姿态稳定性。也需要代表性明暗、粉紫光和生长阶段的独立掩码标注与跨室检查；质量规则须在训练折锁定，再对测试折原样应用。先解决这些问题，才评估 H90 合格帧能否覆盖每个主截点。
- **2023 的用途和限制**：[预试验 v1](https://doi.org/10.4121/e1ee9de9-6ce9-4502-a37c-34b5b1372bed.v1) 沿用 [阶段 0 已验证](data_audit.md) 的 479 个官方单株标签连接和 143 个唯一破坏性测量连接。可用于单株视角下的图像特征对人工株高、叶面积等观测算子标定；单例叶面积标签不一致须按来源保留并解决。固定俯视冠层的可靠单株或 ROI 真值连接数仍是 0。不能把单株株高直接当 2024 群体 H90，或把覆盖率直接当 LAI；迁移还需要按 2024 密度、视角和生长阶段配对的人工参考，以及清晰的空间抽样协议。
- **数据目前不支持**：18 个目标均不能开展预定的 `开环 / RGB 同化 / RGB-D 同化` H90 机理对照，不能给出深度改善果重 MAE 的结论。下一轮补齐验收后仍沿用独立称重、留一隔间和实际环境轨迹协议，按隔间报告配对 MAE 差异；此协议不是有可验证签发时间的前瞻预报。

`--scope pilot` 只解码 26 个试读帧，`--extra-per-camera N` 为全量模式每机额外尝试设上限；未尝试与尝试失败分开。`--cache-only` 不请求未缓存的图像成员；它仍需要归档目录和配置，已有本次缓存时可复现发布快照。在新环境完整复跑需能访问 4TU，并为本地缓存预留约 20 GB；HTTP 429 时降低并发并稍后重试。可把联网复跑输出指向新目录，以免覆盖这份快照。诊断图使用原图缩略、掩码叠图和该帧自身分位拉伸的深度图；各图的灰度不可直接作定量对比。原图及源缓存不提交，缩略图和派生表沿用 4TU 数据署名，见仓库 README。

实际复跑检查：同一冻结缓存用 8 和 4 个 worker 分别运行，Parquet、两个统计 CSV、来源 JSON 和 26 张诊断图逐字节相同；13 项回归测试全部通过。阶段 0 基线报告、称重表、分折清单、原 Reference 样表、索引和密度记录均与 `faf2852` 一致。
